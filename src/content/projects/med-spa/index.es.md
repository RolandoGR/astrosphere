Este sistema se diseñó para un pequeño negocio de medicina estética con recursos limitados. Usa **AppSheet** como plataforma visual y **Apps Script** para ampliar funciones clave, como la creación automática de carpetas, los reportes de citas y los respaldos de datos.

El objetivo fue entregar una **solución de bajo costo pero muy funcional**, sin sacrificar el nivel de personalización que el negocio necesitaba.
